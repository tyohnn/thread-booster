# 99. 훅 쓸 때 체크리스트

근거: 2026-08-08 수집. 순서대로 자문하라.

인덱스: [../README.md](README.md)

1. **목적이 도달인가 전환인가?** 둘 다 원하면 "양쪽 다"로 표시된 카드만 골라라
   (B-1 → [01_사건브리핑](01_사건브리핑.md), B-2 → [03_목록예고](03_목록예고.md),
   D-1 → [02_논증단계](02_논증단계.md)). 도달만 원하면 D-2([04_완결공지](04_완결공지.md))
   / H-1([05_정리무장식](05_정리무장식.md))도 쓸 수 있다 — 대신 전환은 포기한다
2. **소재에 실제 사건·숫자·팔로워 마일스톤이 있는가?** 없으면 어떤 템플릿도
   작동하지 않는다. 지어내면 B축이 무너진다
3. **번호 매긴 목록을 쓰려는가?** 그렇다면: 이 목록이 최종 답인가, 논거인가?
   - 최종 답(추천/가격표) → 30% 이하만 노출(B-2 규칙), 또는 1개만 내용까지
     → [03_목록예고](03_목록예고.md)
   - 논거(반전 논증) → D-1(C-STEP)로 다 보여줘도 된다 → [02_논증단계](02_논증단계.md)
4. **이모지를 넣으려는가?** 같은 훅 안에 A-NUM 또는 B-AUTH가 반드시 같이 있는지
   확인하라. 없으면 빼라 ([90_안티패턴](90_안티패턴.md)의 "이모지 단독" 참고)
5. **본문에 무엇을 남겨뒀는가?** 훅에 다 쓰면 X-CLOSED다. 핵심 숫자·결론·해석 중
   최소 하나는 반드시 본문으로 미뤄라
6. **감사·근황 글인가?** 고난→극복→미완의 목표 3단 구조가 있는지 확인하라. 숫자
   자랑만 있으면 X-NOPAY다 ([90_안티패턴](90_안티패턴.md) 참고)
7. **마지막 자문**: "이 훅만 읽고 만족하나?" 만족하면 실패다. 다시 써라
   (SKILL.md 원칙 그대로)
