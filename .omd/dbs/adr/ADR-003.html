결정일
2026-08-09

Context

배포도 로그인도 없다. localhost에서 나 혼자 쓴다. 필요한 것은 표·차트·상세 페이지이고, 데이터는 로컬 파일에 있다.

Decision

  • Next.js(App Router) 를 로컬에서 실행한다. 서버 컴포넌트에서 DuckDB를 직접 질의한다
  • 차트는 Recharts. 필요한 것은 막대·히스토그램·산점도 정도다
  • 인증·미들웨어·멀티테넌시는 넣지 않는다

Consequences

  • 실행은 pnpm dev 한 줄. 데이터 갱신은 별도 명령
  • 배포 관련 작업은 v1 범위에서 전부 제외한다

Alternatives considered

대안평가
Streamlit·Observable 등 노트북형만들기는 빠르지만 체인 상세 같은 문서형 화면이 어색하다
정적 사이트 + 전체 데이터 번들10MB 넘는 JSON을 브라우저에 올려야 하고 갱신마다 빌드가 필요하다

근거

  • 서버에서 질의하면 22,437행을 브라우저로 내려보낼 필요가 없다
  • 나중에 배포로 전환할 때 구조를 다시 짜지 않아도 된다
  • 이미 익숙한 스택이라 v1까지의 거리가 짧다
