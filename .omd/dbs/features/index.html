Features

ID Title Summary Status
F-001 계정 레지스트리 추적할 스레드 계정을 등록·조회·비활성화한다. 핸들, 별칭, 활성 여부, 마지막 수집 시각, 누적 체인·글 수를 갖는다. active
F-002 퍼머링크 수집 실행기 코드 목록을 받아 퍼머링크의 SSR JSON을 파싱해 raw JSONL로 append한다. 로그인 불필요. active
F-003 신규 글 발견 계정의 새 글 코드를 찾아 수집 대기열에 넣는다. 로그인 없이 도는 경로는 커버리지가 약 2일이라 매일 돌려야 한다. active
F-004 마지막 글 조회수 보강 수집 각 체인의 마지막 글 코드로 시드를 만들어 조회수를 받아온다. 완주율 계산의 전제다. active
F-005 정규화와 체인 재구성 raw JSONL을 읽어 posts·chains로 정규화한다. 체인은 SSR 페이로드의 스레드 구조를 근거로 재구성한다. active
F-006 관측 시계열 적재 수집할 때마다 글별 좋아요·댓글·재게시·조회수를 관측 시점과 함께 append한다. active
F-007 로컬 스토어 빌드 정규화 산출물을 단일 분석 스토어(DuckDB 파일)로 적재한다. 대시보드는 이 파일만 읽는다. active
F-008 수집 콘솔 계정별 수집 상태, 마지막 실행 결과, 실패 건수, 관측 시점 목록을 한 화면에서 본다. 초안
F-009 계정 목록과 요약 계정별로 체인 수, 중앙 훅 조회수, 참여율, 중앙 유지율, 마지막 수집일을 한 표에 보여준다. 초안
F-010 체인 목록 정렬·필터 체인 1,722개를 표로 보여주고 정렬·필터한다. 행은 훅 앞 60자, 날짜, 길이, 훅 조회수, 좋아요, 유지율, 월별 배수를 갖는다. 초안
F-011 체인 상세 체인의 글을 seq 순서로 전문 표시하고 글마다 지표를 붙인다. 상단에 체인 요약과 퍼널(F-014)을 둔다. 초안
F-012 글 전문 검색 30,523개 글의 본문을 검색한다. 결과에서 체인 상세로 이동한다. 초안
F-013 스냅샷 성장 추이 같은 글의 관측 시점별 값을 선그래프로 보여준다. 초안
F-014 체인 퍼널 차트 한 체인의 1번·2번·마지막 글 조회수를 막대로 그리고 구간별 잔존율을 표시한다. 초안
F-015 유지율 분포와 훅 유형 비교 전체 유지율 분포를 히스토그램으로 보여주고, 훅 유형·계정·체인 길이별로 나눠 비교한다. 초안
F-016 이상 체인 추출 두 종류의 예외를 자동으로 추린다. 초안
F-017 훅 유형 분류기 훅 본문을 보고 유형을 붙인다. 1차는 규칙 기반(이모지·숫자 목록·감탄사 패턴), 수정은 수작업으로 덮어쓴다. 초안
F-018 템플릿 카드 템플릿 하나를 훅 구조, 전개 순서, 주의사항, 심리 기법 태그, 연결 체인으로 구성한다. 초안
F-019 체인을 템플릿으로 승격 체인 상세에서 버튼 하나로 템플릿 초안을 만든다. 길이·유지율·훅 유형 같은 구조 정보만 자동으로 채우고 문장은 복사하지 않는다. 초안
F-020 심리 기법 태깅과 교차 조회 심리 기법 마스터 17개를 관리하고 템플릿에 복수로 붙인다. 기법을 기준으로 역방향 조회한다. 초안
F-021 템플릿 성과 롤업 템플릿에 연결된 체인들의 지표를 집계해 템플릿 카드에 보여준다. 초안
