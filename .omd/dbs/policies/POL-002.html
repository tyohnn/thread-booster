POL-002

저작권 — 표현이 아니라 구조를 가져온다

status
active
summary
남의 문장은 재사용하지 않고, 심리 기법으로 분해해 우리 문장으로 재조립한다
유형
데이터규칙
적용 화면
체인 상세, 템플릿 편집
근거
프로젝트 초기부터의 원칙 — 템플릿화의 전제

Rule

  • 수집한 원문은 분석 목적으로만 보관한다
  • 템플릿에 저장하는 것은 구조(훅 형식, 전개 순서)와 심리 기법이다
  • 원문 문장을 템플릿 본문에 복사하지 않는다. 예시가 필요하면 원본 링크를 건다
  • 발행하는 글은 우리 문장으로 새로 쓴다

Applies when

원문 보관·정규화 산출물·템플릿/분석 산출물 작성 시. REL-001에서는 raw JSONL을 git에 넣지 않는 것까지 포함한다.

Does not apply

짧은 분석용 인용·퍼머링크 링크. 구조·심리 기법 요약.

Rationale

프로젝트 초기부터의 원칙 — 템플릿화의 전제

구현 장치

  • 템플릿 생성 시 체인 원문을 자동 복사하지 않는다. 구조 요약 필드만 채운다
  • 원문이 필요한 곳은 퍼머링크 링크로 대체한다
