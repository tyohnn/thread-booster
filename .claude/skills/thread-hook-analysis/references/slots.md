# 슬롯 문법

훅을 HTML처럼 **구조와 내용으로 분리**한다. 구조가 템플릿이고, 내용은 매번 갈아끼우는 값이다.

```
🚨와... 트럼프가 드디어 중국을 장악하러 간다 ㄷㄷ
(제발 저장해라)
3000조 규모의 미중 패권 전쟁이 시작됐음
```
↓
```
{SIGNAL}{ACTOR}가 {ADVERB} {EVENT} {INTENSIFIER}
{DIRECTIVE}
{SCALE} {SITUATION}
```

이렇게 뚫어두면 **다른 주제로 같은 구조를 재사용**할 수 있다. 그게 이 작업의 목적이다.
표현을 베끼면 저작권 문제가 되지만, 구조는 아이디어라 자유롭게 쓸 수 있다 —
슬롯을 채우는 문장은 반드시 새로 써야 한다.

## 슬롯 사전

슬롯은 **기능** 단위다. 같은 단어라도 하는 일이 다르면 다른 슬롯이다.

### 도입부

| 슬롯 | 하는 일 | 예 |
|---|---|---|
| `{SIGNAL}` | 시각적 정지 신호 | `🚨`, `🚨와...`, `[속보]` |
| `{REACTION}` | 화자의 감정 반응을 먼저 노출 | `와…`, `하…`, `미쳤다` |
| `{ADDRESS}` | 독자 호명 | `한국 개미가`, `통장 3억 이하라면`, `20대라면` |

### 본체

| 슬롯 | 하는 일 | 예 |
|---|---|---|
| `{ACTOR}` | 사건의 주체 (권위 전이가 여기서 일어난다) | `트럼프`, `머스크`, `팔란티어 CEO` |
| `{EVENT}` | 무슨 일이 일어났나 | `이란에 100조원을 주면서`, `반도체 시장에 쳐들어왔다` |
| `{CLAIM}` | 그래서 무엇이 참인가 | `전세계 패권을 완전히 장악했다` |
| `{SCALE}` | 규모를 수치로 | `3000조 규모의`, `2600조를`, `173조짜리` |
| `{ADVERB}` | 사건의 임박·전환을 강조 | `드디어`, `결국`, `방금` |
| `{INTENSIFIER}` | 감정 증폭 꼬리 | `ㄷㄷ`, `ㅋㅋ`, `...` |

### 전환부 ★ 유지율은 대부분 여기서 결정된다

| 슬롯 | 하는 일 | 예 |
|---|---|---|
| `{PROMISE}` | 본문에 뭐가 있는지 **명시하되 내용은 안 준다** | `싹 다 가져옴`, `전부 정리함`, `싹 다 공개` |
| `{STAKES}` | 모르면 무엇을 잃나 | `모르면 ㅈ되는`, `3년 뒤에 후회하기 싫으면` |
| `{DIRECTIVE}` | 다음 행동 지시 | `(제발 저장해라)`, `(무조건 읽어라)`, `(놓치지 마라)` |
| `{TEASER}` | 목록의 **일부만** 노출 | `TOP 30` 중 1~4번만 |
| `{COUNT}` | 분량 예고 | `TOP 5`, `7가지`, `TOP 30` |

### 안티 슬롯

발견하면 그대로 기록하라. 무엇이 유지율을 죽였는지가 템플릿의 핵심 정보다.

| 슬롯 | 왜 해로운가 |
|---|---|
| `{FULLLIST}` | 목록 전체를 훅에 넣어 다음 글의 존재 이유를 없앤다 |
| `{CONCLUSION}` | 결론을 훅에서 말해버린다 |
| `{GRATITUDE}` | 감사·근황. 적재 자체가 없다 |

## 표기 규칙

**추출된 템플릿**은 슬롯만 남긴다.

```
{SIGNAL}{ACTOR}가 {ADVERB} {EVENT} {INTENSIFIER}
{DIRECTIVE}
{SCALE} {SITUATION}
{ADDRESS} 모르면 {STAKES} {PROMISE}
```

**태깅된 실례**는 원문에 슬롯을 겹쳐 쓴다. 검증할 때 원문과 대조할 수 있어야 한다.

```
[SIGNAL:🚨와...] [ACTOR:스페이스X]가 [SCALE:2600조]를 [EVENT:쓸어 담는다]
[ADDRESS:한국 개미가] 모르면 [STAKES:ㅈ되는] 정보 [PROMISE:싹 다 가져옴]
[DIRECTIVE:(뒤쳐지기 싫으면 제발 놓치지 마라)]
```

## 슬롯을 새로 만들어도 되나

된다. 위 사전은 `beyond.cho`·`ho_ho_ju_ju`·`badakstock` 표본에서 귀납한 것이라
다른 계정에는 없는 구조가 나온다. 예를 들어 `afternoonlibrary`의 `<꺾쇠 제목>` 포맷은
기존 슬롯으로 안 잡힌다.

새 슬롯을 만들 때는 **기능으로 이름 짓고**, 어떤 심리 기법을 수행하는지 함께 적어라.
슬롯이 심리 기법과 연결되지 않으면 그건 그냥 문장 조각이지 템플릿 부품이 아니다.
